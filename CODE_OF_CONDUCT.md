# Kode Etik

Proyek ini mengikuti [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Singkatnya: bersikap hormat dan profesional di issue, pull request, dan
review. Kritik ditujukan ke kode, bukan ke orangnya. Pelecehan, bahasa
kasar, dan membagikan data pribadi orang lain (termasuk data pembeli)
tidak ditoleransi.

Laporkan pelanggaran secara privat ke pemilik repo
([@nicholaswijaya004](https://github.com/nicholaswijaya004)). Laporan
ditangani secara rahasia.
